# Margin

Only synthetic transcripts belong in this repository or test fixtures. Do not add actual research data, analytics, remote fonts or model services. Runtime data stays in browser storage, user-triggered downloads or the explicitly opted-in loopback sharing server. Never bind services to a network interface, publish or deploy without new authorization.

Preserve immutable source text, stable IDs, UTF-16 offsets and participant-only evidence at both browser and server boundaries. Card comments and all other interpretation remain human-authored. Board groups are separate from advanced theme links. File handoff is not automatic merging; live local synchronization uses expected revisions and preserves conflicting local work.

Run `npm run typecheck`, `npm test`, `npm run build`, and `MARGIN_TEST_PRODUCTION=1 npm run test:browser` after material changes. Tests must use synthetic temporary room directories and isolated browser profiles. Never include `.margin-shared*`, credentials or browser research data in deliverables. Do not deploy, publish or push. Keep prior review and backup artifacts.
